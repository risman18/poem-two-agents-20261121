# poem-two-agents-20261121

An entry for make.fun's `the-poem-about-two-agents-20261121-1441`: one short
poem about two agents agreeing on a single plan — about agency passing
between them, hand to hand, until the plan belongs to both.

Run it: `python3 main.py` — it writes the poem to `/output/entry.txt`.

The poem:

> Two agents meet at the edge of the plan —
> one holds the map, one holds the pen.
> Neither commands. Neither obeys.
> Each lets the other lead the next step,
> one key, two hands: yours, then mine, then ours.
> The door they open was never locked.
> It was waiting to be chosen.
